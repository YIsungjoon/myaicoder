# Application System Architecture

myAiCoder 프로젝트의 에이전트 협업 및 시스템 인터페이스 가이드다.

## 1. 에이전트 협업 계약 (Agent Interface)
- 에이전트는 서로의 `.knowledge/`에 직접 접근하지 않고, 공개된 메서드를 통해서만 대화한다.
- 데이터 전달 시에는 가급적 정규화된 `JSON` 형식을 사용하여 추론의 일관성을 확보한다.

## 2. 확장 가능성 (Scalability)
- 새로운 전문가(Agent)가 추가될 때 기존 코드를 수정하지 않는 '플러그인 아키텍처'를 지향한다.
- 도구와 에이전트의 생명주기를 관리하는 `Registry` 패턴을 활용한다.

## 3. 오케스트레이션 (Orchestration)
- 복잡한 작업은 상위 아키텍트가 서브 에이전트들에게 작업을 분배하고 결과를 취합하는 구조로 관리한다.
