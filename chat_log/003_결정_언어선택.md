# 003. 결정: 구현 언어 선택

**날짜**: 2026-03-13
**작업 유형**: 기술 결정
**Feature**: ai-coder-cli

## 결정 내용

### 채택: 옵션 C (Python 중심)
- **메인**: Python (CLI, MCP Client/Server, Core Engine, LLM 추론)
- **IDE 확장**: TypeScript (VS Code Extension)

### 사유
- 프로젝트 초기 단계이므로 프로토타이핑 속도와 LLM 실험 유연성 우선
- vLLM/llama-cpp-python 등 AI 생태계 직접 통합 가능
- 단일 언어로 CLI + MCP + 추론 전체 구현 가능

### 향후 전환 계획
- MVP 완성 및 성능 벤치마크 후 옵션 A(TS+Py) 또는 옵션 B(Rust+TS)로 전환 검토
- 전환 용이성을 위해: 모듈 분리, 인터페이스 기반 설계, JSON 기반 설정

## 논의 과정
1. 5개 언어 분석 (TypeScript, Rust, Python, Go, C++)
2. 3가지 조합 옵션 제시
3. 사용자: "초기이므로 옵션 C, 추후 A 또는 B 전환" 결정
