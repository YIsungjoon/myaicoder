# 001. 프로젝트 초기 설정

**날짜**: 2026-03-13
**작업 유형**: 환경 설정
**프로젝트 레벨**: Enterprise

## 결정 사항
- 기본 언어: 한국어 (코드/주석은 영어)
- 프로젝트 레벨: Enterprise (마이크로서비스/K8s/Terraform)
- 문서 구조: docs/pdca (01-plan ~ 05-act)
- 로그 구조: chat_log (순번 기반 추적)
- 아키텍처: Clean Architecture (4-Layer) + Monorepo (Turborepo)

## 기술 스택
- **Frontend**: Next.js 14+, TypeScript, Tailwind CSS, TanStack Query, Zustand
- **Backend**: Python FastAPI, PostgreSQL, Redis
- **Infra**: AWS EKS, Terraform, Kubernetes, ArgoCD
- **CI/CD**: GitHub Actions, Docker

## 생성된 파일
- `CLAUDE.md` - 프로젝트 전체 컨텍스트
- `apps/CLAUDE.md` - 프론트엔드 컨벤션
- `services/CLAUDE.md` - 백엔드 컨벤션
- `infra/CLAUDE.md` - 인프라 컨벤션
- `turbo.json` - Turborepo 설정
- `pnpm-workspace.yaml` - 워크스페이스 설정
- `docker-compose.yml` - 로컬 개발 환경 (PostgreSQL, Redis)
- `.gitignore`
- `infra/k8s/base/namespace.yaml` - K8s 네임스페이스
