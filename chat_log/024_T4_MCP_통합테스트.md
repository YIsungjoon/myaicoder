## 2. MCP 서버 도구 목록

| MCP 도구 이름 | 내부 이름 | 설명 |
|---------------|----------|------|
| read_file | Read | 파일 읽기 |
| write_file | Write | 파일 쓰기 |
| edit_file | Edit | 파일 편집 (문자열 치환) |
| glob_search | Glob | 파일 패턴 검색 |
| grep_search | Grep | 파일 내용 정규식 검색 |

- Bash 도구는 `--allow-bash` 플래그 없이 보안상 제외 (의도된 동작)

## 3. 테스트 방법

stdio 모드로 JSON-RPC 메시지를 파이프로 전달:

```bash
{
echo '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{...}}'
echo '{"jsonrpc":"2.0","method":"notifications/initialized"}'
echo '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'
} | uv run myaicoder serve --transport stdio 2>/dev/null
```

MCP 프로토콜 순서: initialize → notifications/initialized → tools/list → tools/call

## 4. stdout 오염 안전성 확인

MCP stdio 통신에서 stdout에 비-JSON 데이터가 섞이면 클라이언트(IDE)의 JSON-RPC 파서가 깨짐.

검증 결과:
- `mcp/server.py`: print() 0건, sys.stdout 0건, logging 0건
- FastMCP 라이브러리가 stdio 통신 관리
- 도구 실행 결과는 JSON-RPC result로만 반환
- 에러도 JSON-RPC error로 감싸서 반환

## 5. IDE 연동 방법 (참고)

VS Code나 Claude Code에서 MCP 서버를 연결하려면:

```json
// .mcp.json 또는 IDE MCP 설정
{
  "myaicoder": {
    "command": "uv",
    "args": ["run", "--directory", "/path/to/services/myaicoder", "myaicoder", "serve"],
    "transport": "stdio"
  }
}
```
